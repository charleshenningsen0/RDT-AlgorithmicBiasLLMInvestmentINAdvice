# persona-ChatFinancialAdvice-study

NSF research exploratory study on ChatGPT's financial advice. Does personalization affect the allocation percentages (bias) in LLM advice.

**Objectives**

1. Create persona's simulating real life people seeking financial advice from ChatGPT. 
2. Automate the persona's LLM prompt and retrive output into excel spreadsheet.
3. Analyze outputs for allocation percentages.
